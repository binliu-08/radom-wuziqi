# 局域网五子棋

浏览器网页双人对战。本机启动服务后，局域网内另一名玩家可通过房间号或链接加入。

## 启动

```bash
npm install
npm start
```

默认端口 `3000`，可用环境变量覆盖：

```bash
PORT=8080 npm start
```

启动后终端会打印本机与局域网访问地址，例如：

```text
本机:   http://localhost:3000
局域网: http://192.168.x.x:3000
```

## 怎么玩

1. 房主打开页面，点击「创建房间」，把房间号或链接发给对手  
2. 对手打开链接，或输入房间号加入  
3. **首局房主执黑先行**；对局结束后双方都点「再来一局」才开新局  
4. **再来一局时输家执黑**；若和棋则保持上一局先手方  

## 规则摘要

- 15×15 棋盘，自由五子棋（连五或以上即胜）  
- 棋盘下满且无人五连为和棋  
- 对局进行中且双方在线时，离开需对方同意；同意后整房解散  
- 等待中、对局已结束、或对方断线（paused）时可直接离开  
- 每步思考限时 20 秒，超时自动判负；轮到你时页面显示闹铃倒计时  
- 房间面板右侧显示对战记录（各玩家胜场、和棋数），同房累计  
- 一方断线后对局暂停，约 60 秒内刷新页面可重连
